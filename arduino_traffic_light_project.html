ARDUINO PROJECT

버튼으로 제어하는 신호등

Arduino UNO와 LED 3개, 버튼을 이용해 빨간불 → 노란불(3초) → 초록불로 전환하고, 다시 버튼을 누르면 초록불 → 노란불(3초) → 빨간불로 돌아가는 프로젝트입니다.

실제 제작 사진

사용자가 제공한 실제 Arduino 회로 사진을 프로젝트 메인 이미지로 사용했습니다.

동작 시뮬레이션

빨간불
버튼을 누르면 노란불로 전환됩니다.

핀 연결

D8빨간 LED
D9노란 LED
D10초록 LED
D2버튼 / INPUT_PULLUP

프로그램 동작 순서

1
초기 상태
빨간 LED가 켜지고 노란색과 초록색은 꺼집니다.
2
버튼 입력
버튼을 누르면 디바운싱 후 노란 LED가 켜집니다.
3
3초 대기
millis()를 이용해 지연 없이 3초를 측정합니다.
4
상태 전환
초록 모드이면 초록불, 아니면 빨간불로 전환합니다.

Arduino 코드

const int RED = 8;
const int YELLOW = 9;
const int GREEN = 10;
const int BUTTON = 2;

bool greenMode = false;
bool changing = false;

bool lastReading = HIGH;
bool stableButton = HIGH;
unsigned long debounceTime = 0;
unsigned long yellowStart = 0;

void setLights(bool red, bool yellow, bool green) {
  digitalWrite(RED, red);
  digitalWrite(YELLOW, yellow);
  digitalWrite(GREEN, green);
}

void setup() {
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BUTTON, INPUT_PULLUP);

  setLights(HIGH, LOW, LOW);
}

void loop() {
  bool reading = digitalRead(BUTTON);

  if (reading != lastReading) {
    debounceTime = millis();
  }

  if (millis() - debounceTime > 50) {
    if (reading != stableButton) {
      stableButton = reading;

      if (stableButton == LOW && !changing) {
        changing = true;
        yellowStart = millis();
        setLights(LOW, HIGH, LOW);
      }
    }
  }

  lastReading = reading;

  if (changing && millis() - yellowStart >= 3000UL) {
    changing = false;
    greenMode = !greenMode;

    if (greenMode) {
      setLights(LOW, LOW, HIGH);
    } else {
      setLights(HIGH, LOW, LOW);
    }
  }
}
